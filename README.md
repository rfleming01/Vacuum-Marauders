# Vacuum Marauders
**Version: 1.1**
* Added "asteriod fragments", where the destroyed asteriods split into two faster and smaller asteriods
* Added a scrap mechanic, where destroying the enemy objects adds to the scrap score, and damage to enemy objects is multiplied by the scrap score (the base damage is 10)
